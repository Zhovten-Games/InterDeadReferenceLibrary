## Verification

Install the Node tool dependencies with `npm --prefix tools/node_browser/terminal_scene_video_builder ci`, then run `node tools/warden.mjs`. Python 3.10+ and Node 24.19+ run the source and regression checks. Media acquisition and hardware-dependent processing retain their documented prerequisites.
