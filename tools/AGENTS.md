# Tool implementation scope

Each tool keeps its documented language, dependencies and entry point. Python
uses its existing module conventions; browser tools keep native JS and local
package contracts. Repository governance applies to provenance, verification,
licensing and source/generated boundaries. Existing session inputs and outputs,
external packages and asset notices retain their attributed status. New builds
and node_modules stay outside source commits. Run the repository WARDEN; run a
tool's documented end-to-end command when changing its media/runtime behavior.
